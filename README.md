# airline-booking-analysis
This dataset contains airline booking information that can be used for data analysis, visualization, and business insights.										
Key Features:										
passengers_count: Number of passengers in each booking.										
booking_origin: Country where the booking was made.										
trip_type: Type of trip (One Way – Round Trip – Circle Trip).										
flight_day: Day of the flight (Sunday–Saturday).										
length_of_stay: Duration of stay in days.										
flight_hour: Hour of the flight.										
extra_services: Customer preferences for additional services (baggage, meals, seat selection).										
🔹 Use Cases:										
Analyzing booking trends by day, country, and trip type.										
Identifying customer preferences for extra services.										
Building dashboards for business decision-making.										
📌 Source: Kaggle – Airlines Booking Dataset
